# .Antasofa — Portfolio

Portofolio pribadi Antasofa, Mobile App Developer. Dibikin pake HTML, CSS, dan JavaScript doang — no framework ribet, satu file `index.html`.

## Isi

- **Hero** — intro + stats (3+ tahun exp, 7+ live products, AI workflow)
- **Projects** — 7 app yang udah rilis ke Play Store (Ferry Ticketing, POS, Logistics Tracking, Parenting Platform, Draiv, LoundryGo, Tire Repair Locator)
- **Experience** — Prahu Hub, Morning Glory Enterprise, Elisoft, Freelance (2019–2021)
- **Tech Stack** — Mobile (Flutter, Kotlin, Jetpack Compose), Backend & Web (Express.js, TypeScript, Supabase, Firebase, React, Next.js, Tailwind), Design (Figma)
- **About & Services** — ringkasan keahlian + layanan
- **Contact** — link sosial & kolaborasi

Efek: custom cursor, progress bar, scroll reveal, dan marquee — semua vanilla JS.

## Cara buka

Buka aja `index.html` di browser, atau pake live server:

```bash
npx serve .
```

## Deploy

Bisa langsung di deploy ke Vercel, Netlify, GitHub Pages, atau static host mana aja. Saat ini live di GitHub Pages.
