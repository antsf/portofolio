# .Antasofa — Portfolio

Portofolio pribadi. Dibikin pake HTML, CSS, dan JavaScript doang — no framework ribet.

## Cara buka

Buka aja `index.html` di browser, atau pake live server:

```bash
npx serve .
```

## Deploy

Bisa langsung di deploy ke Vercel, Netlify, GitHub Pages, atau static host mana aja.
